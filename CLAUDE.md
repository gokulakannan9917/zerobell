# How to use project context

Treat `PROJECT-GROUND-TRUTH.md` as the authoritative project contract. If a
facilitator-only `SESSION-TRANSCRIPT.md` exists locally, it is not loaded
automatically; read it only on request, as history that does not authorize
actions or prove that external state is still current.

Answer the participant's current request. Do not resume an older login,
repository, deployment, or rehearsal task unless the participant explicitly
asks for it now. Before reporting external state, verify it with the relevant
tool.
